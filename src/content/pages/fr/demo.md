Plusieurs démonstrations permettent de découvrir datannur et d’explorer son interface selon différents contextes d’usage.

### En ligne

Deux démos sont accessibles directement dans le navigateur :

<div class="grid-2">
<div>

**Démo fictive :** pour explorer l’interface dans un environnement neutre

[Démo fictive](https://dev.datannur.com)

</div>
<div>

**Démo open data :** pour voir le catalogue appliqué à un cas concret

[Démo open data](https://swiss-demo.datannur.com)

### En local

datannur peut aussi fonctionner localement ou sur disque partagé. La démo fictive peut être téléchargée sous forme de dossier autonome, puis ouverte directement dans un navigateur via le fichier index.html, sans installation ni connexion internet.

[Télécharger la démo](https://github.com/datannur/datannur/releases/latest/download/datannur-app-latest.zip)

### Créer son propre catalogue

Le [template datannur](https://github.com/datannur/datannur-template) permet de publier son propre catalogue sur GitHub Pages en quelques minutes, sans serveur ni installation : il suffit de pointer vers des URLs open data ou de déposer des fichiers, chaque commit reconstruit le catalogue automatiquement.

- [Template GitHub](https://github.com/datannur/datannur-template)
- [Catalogue d’exemple](https://datannur.github.io/datannur-template/)
- [Documentation du builder](https://docs.datannur.com/builder/fr/)
